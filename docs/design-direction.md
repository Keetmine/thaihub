# Дизайн-направление (утверждено владельцем 2026-08-22)

Владелец прислала 7 референсов (Behance/Dribbble-стилистика). Решения:
тёмная тема остаётся основной, акцент остаётся оранжевым, админка
остаётся фиолетовой. Редизайн — эволюция текущих токенов
(globals.css уже даёт тёмный фон #0a0a0c, акцент #ff6a3d, Space
Grotesk, стеклянную навигацию, ambient-градиент), а не замена.

## Что общего у референсов — целевой язык

- **Bento-сетки**: контент — мозаика карточек разного размера, а не
  вертикальная стопка одинаковых строк. Крупная карточка-герой + мелкие
  вокруг.
- **Крупная editorial-типографика**: большие display-заголовки, рядом —
  микро-подписи капсом (eyebrow уже есть), нумерация секций (01/02/03),
  стрелки ↗ на ссылках.
- **Тёплые оранжевые градиенты и свечения** как фон карточек и hero —
  не плоский цвет, а «закатные» переливы (референсы onpoint, podcast).
- **Стекло**: полупрозрачные панели с blur поверх изображений
  (pill-nav уже такой — распространить на карточки/оверлеи).
- **Изображение как фон карточки**: постер/фото на всю карточку,
  текст поверх на градиентной подложке — вместо «аватарка слева,
  текст справа».
- **Контраст тёмного и кремового**: в тёмном layout отдельные карточки
  могут быть светлыми (кремовыми) — так у Lumoo/MadeSongs; даёт
  иерархию без второго акцентного цвета.
- **Капсулы и круглые кнопки**: pill-чипы для тегов/фильтров, круглые
  иконочные кнопки, большие радиусы (1.5–2rem — токены уже такие).

## Практические следствия для MyBLHub

- Главная и лендинг — bento из крупных постерных карточек (ближайшие
  события, новые релизы, любимые артисты), а не списки плашек.
- Карточка события/артиста/дорамы: постер как фон или крупный постер
  сверху; типы контента различать оформлением, не только текстом.
- Секции с нумерацией и eyebrow-подписями; «Как это работает» в стиле
  RideQ (01 Book / 02 Track).
- Тёплые градиентные подложки для hero, пейволла, пустых состояний.
- Кремовые карточки — для акцентных блоков (CTA, подписка, ачивки).
- Анимации: плавные появления со stagger, hover-подъёмы уже есть —
  добавить переходы между страницами и скелетоны в той же стилистике.

## Референсы (по присланным картинкам)

1. onpoint (identity, glass + warm orange waves) — стекло, капсулы,
   микро-лейблы.
2. Y68 street basketball — постер-объект + крупная типографика +
   карточка события слева (прямо наш кейс «карточка события»).
3. MadeSongs — чёрный/кремовый/красный, плеер-карточки, editorial.
4. Puls AI — светлый вариант: крупные заголовки с выделением цветом,
   чипы-капсулы, нумерованные тёмные карточки (для лендинга).
5. RideQ — bento-мозаика «WHO WE ARE / WHY / HOW IT WORKS» с
   нумерацией и круглыми кнопками.
6. Lumoo — тёмный + кремовый + тёплое свечение, конфигуратор в
   карточке (ближе всего к целевой атмосфере продукта).
7. Podcast-платформа — тёплый градиентный hero со стеклянными
   виджетами поверх (образец для нашего hero и /events).
