файл в docs/, который смотрит вперёд; выполненное отсюда удаляется, а
поведение документируется в соответствующем feature-файле).

## А. Хвосты текущей работы

      тематических коммитов, запушить.
- [x] А2. Картинки: 21 172 файла локально, все в WebP (1334 МБ → 803 МБ),

## Б. Блокеры прода

- [x] Б1. Реверс-прокси с HTTPS (Caddy) в docker-compose, домен
      myblhub.com → сервер.
- [x] Б2. Бэкапы: pg_dump по крону + копия public/uploads.
- [x] Б3. Rate-limiting на логин/регистрацию (in-memory, без внешних
      зависимостей).
- [x] Б4. Admin-сессии: серверные сессии вместо куки=секрет (по образцу
      пользовательских).
- [x] Б5. Регистрация по инвайтам (код при регистрации, генерация в
      админке).
- [x] Б6. Прод-гигиена: /api/health + healthcheck, CI, robots.txt —
      сделано; Sentry отложен (нужен аккаунт/DSN — решить отдельно).

## В. Подписка

- [x] В1. Срок подписки: `premiumUntil DateTime?` вместо вечного
      boolean; выдача из админки — на месяц; истечение проверяется в
      гейтах; напоминание в Telegram за 3 дня до конца.
- [x] В2. Оплата через Telegram (Stars/Payments): кнопка в заглушке →
      инвойс в боте → вебхук продлевает premiumUntil на месяц.
- [x] В3. Продающая заглушка подписки: что внутри, цена, кнопка оплаты.

## Г. Функционал

- [x] Г1. Пресейл-напоминания в Telegram («через час открываются
      продажи») — для событий из избранного/«иду».
- [x] Г2. Уведомления о друзьях («Аня идёт на …») + управление на сайте:
      подписаться/отписаться на уведомления конкретного друга.
- [x] Г4. Вкладка «Что посетить» в поездке: локации съёмок дорам
      (приоритет — из избранного/просмотренного) рядом с датами поездки,
      с картой.
- [x] Г6. Заметки к событиям — личные или видимые друзьям.
- [x] Г7 (часть). Оффлайн-кэш PWA (sw.js: network-first страницы,
      cache-first статика). Web-push отложен — Telegram уже покрывает
      уведомления; вернуться, если понадобится браузерный канал.
- [x] Г8. Настройки приватности профиля (скрыть активность/актёров;
      сейчас профиль виден всем залогиненным).
- [x] Г10. Админ-дашборд: юзеры/подписки/последние импорты одним
      экраном.

## Д. Геймификация

- [x] Д1. Вкладка «Статистика» в кабинете: счётчики (концерты, площадки,
      актёры вживую, локации, дорамы, поездки, дни в Таиланде), топ
      актёров по посещениям, карта посещённого, разбивка по годам.
- [x] Д2. Ачивки (~20, считаются из существующих данных): бейджи в
      кабинете и публичном профиле, прогресс до следующей,
      поздравление от бота в Telegram при получении.

Отложено из геймификации: «Итоги года» (к декабрю), уровни/лидерборды
(посмотреть, как зайдут ачивки).
