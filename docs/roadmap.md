# Roadmap

Согласованный план работ (не описание текущего поведения — единственный
файл в docs/, который смотрит вперёд; выполненное отсюда удаляется, а
поведение документируется в соответствующем feature-файле).

## А. Хвосты текущей работы

- [ ] А1. Закоммитить весь накопленный дифф (~123 файла) серией
      тематических коммитов, запушить.
- [ ] А2. Картинки: дождаться конца закачки TMDB → повторный прогон
      `backfill-tmdb-images.ts` за упавшими (403/fetch failed) →
      `convert-uploads-webp.ts` по всему архиву.
- [ ] А3. Dockerfile: `playwright install --with-deps chromium` в
      runner-образ — иначе кнопки blscene/GMMTV падают на проде.
- [ ] А4. (руками, @BotFather) `/setdomain` → myblhub.com для
      @myblhub_bot, иначе виджет входа не рендерится.

## Б. Блокеры прода

- [ ] Б1. Реверс-прокси с HTTPS (Caddy) в docker-compose, домен
      myblhub.com → сервер.
- [ ] Б2. Бэкапы: pg_dump по крону + копия public/uploads.
- [ ] Б3. Rate-limiting на логин/регистрацию (in-memory, без внешних
      зависимостей).
- [ ] Б4. Admin-сессии: серверные сессии вместо куки=секрет (по образцу
      пользовательских).
- [ ] Б5. Регистрация по инвайтам (код при регистрации, генерация в
      админке).
- [ ] Б6. Прод-гигиена: /api/health + healthcheck app-контейнера,
      Sentry, CI (tsc+eslint+build), robots.txt.

## В. Подписка

- [ ] В1. Срок подписки: `premiumUntil DateTime?` вместо вечного
      boolean; выдача из админки — на месяц; истечение проверяется в
      гейтах; напоминание в Telegram за 3 дня до конца.
- [ ] В2. Оплата через Telegram (Stars/Payments): кнопка в заглушке →
      инвойс в боте → вебхук продлевает premiumUntil на месяц.
- [ ] В3. Продающая заглушка подписки: что внутри, цена, кнопка оплаты.

## Г. Функционал

- [ ] Г1. Пресейл-напоминания в Telegram («через час открываются
      продажи») — для событий из избранного/«иду».
- [ ] Г2. Уведомления о друзьях («Аня идёт на …») + управление на сайте:
      подписаться/отписаться на уведомления конкретного друга.
- [ ] Г4. Вкладка «Что посетить» в поездке: локации съёмок дорам
      (приоритет — из избранного/просмотренного) рядом с датами поездки,
      с картой.
- [ ] Г6. Заметки к событиям — личные или видимые друзьям.
- [ ] Г7. Web-push / оффлайн-режим PWA (план поездки и афиша без сети).
- [ ] Г8. Настройки приватности профиля (скрыть активность/актёров;
      сейчас профиль виден всем залогиненным).
- [ ] Г10. Админ-дашборд: юзеры/подписки/последние импорты одним
      экраном.

## Д. Геймификация

- [ ] Д1. Вкладка «Статистика» в кабинете: счётчики (концерты, площадки,
      актёры вживую, локации, дорамы, поездки, дни в Таиланде), топ
      актёров по посещениям, карта посещённого, разбивка по годам.
- [ ] Д2. Ачивки (~20, считаются из существующих данных): бейджи в
      кабинете и публичном профиле, прогресс до следующей,
      поздравление от бота в Telegram при получении.

Отложено из геймификации: «Итоги года» (к декабрю), уровни/лидерборды
(посмотреть, как зайдут ачивки).
