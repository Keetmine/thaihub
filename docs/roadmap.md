## Почта (отложено 2026-08-18, решение за владельцем)

- [ ] Выбрать и подключить почтовый сервис. Ограничение: аудитория в
      РФ, Cloudflare-решения не подходят. Исследовано:
      бесплатных ящиков на домене с SMTP не осталось — Яндекс 360 и
      VK WorkSpace платные (~250–310 ₽/юзер/мес), у Zoho бесплатный
      тариф только webmail (без SMTP/IMAP). Бесплатное комбо: Zoho
      Free (ящик admin@, читать через веб) + Unisender Go (SMTP,
      1500 писем/мес бесплатно, российский). Проще всего — платный
      Яндекс 360: один сервис закрывает и ящик, и SMTP
      (smtp.yandex.ru:465, пароль приложения). Шаги — в docs/deploy.md.
      Код готов весь: SMTP_* в .env + admin_notify_email в настройках.
- [ ] Пока почты нет: сброс пароля недоступен (вход через
      Google/Telegram работает), ответы на обращения — с личного ящика
      через mailto, админ-уведомления — только Telegram.
