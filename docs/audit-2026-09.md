Полный аудит сайта (2026-09-09, пять параллельных проходов: безопасность,
удобство, SEO и данные, производительность, продукт). Решение владельца:
**делаем всё из списка**, кроме отдельной страницы пейринга (пары
достаточно на странице артиста); пробный лимит — делаем.

Статус правок отмечается по ходу; что сделано — вычёркивать не надо,
помечать «✓ сделано (дата)». Этот файл — источник задач до полного
разбора.

## 1. Дыры и баги (чинить первыми)

1. Брони поездки: `saveTripBooking`/`deleteTripBooking` не проверяют
   авторство — участник может переписать/раскрыть/удалить чужую
   приватную бронь (trips/actions.ts:1055, :1143; для дел и личных
   событий `canTouchItem` есть, для броней — нет). ✓ сделано
   (2026-09-09): `guardBookingTouch` в trips/actions.ts — бронь правят
   автор и владелец поездки, чужая приватная отвечает «не найдена»
   даже владельцу; карандаш в UI по тому же правилу.
2. `addComment` (reviews/actions.ts:102) не зовёт `canSeeMeetup`:
   посторонний пишет комментарии под закрытой встречей сообщества.
   `saveReview` для встреч проверяет только «событие прошло».
   ✓ сделано (2026-09-09): оба экшена для kind === "event" зовут общий
   гейт (существование + `canSeeMeetup`), постороннему — ошибка
   значением с тем же «Событие не найдено», что у 404 страницы.
3. Закрытое сообщество отдаёт гостю описание (левая колонка + meta
   description) — обещано «название + „закрытое“»
   (communities/[id]/page.tsx:256, :79). ✓ сделано (2026-09-09):
   постороннему на закрытом — только название + пометка (без описания,
   обложки, числа участников, места и кнопки входа), meta description —
   общая фраза раздела.
4. Закрытый вид обсуждений: карточка темы без заголовка показывает
   гостю первые 90 символов ТЕКСТА (DiscussionsTab select тянет text,
   PostCard: title ?? excerpt) — обещаны «заголовки без содержимого».
   ✓ сделано (2026-09-09): снаружи `text` не выбирается из базы вовсе,
   тема без заголовка подписывается «Тема без названия» (обе локали).
5. `photoUrl` профиля пишется без валидации и уходит в голый img —

   валидируются — перенести тот же разбор. ✓ сделано (2026-09-09):
   общий `parseUploadUrl` (src/lib/uploadUrl.ts, «только свой

6. Регрессия 2026-09-09: при переводе картинок на общую FileDropzone
   потерян запрет сохранять, пока файл едет (MeetupForm,
   CreateCommunityButton; комментарии в коде обещают запрет, которого
   нет). Нужен onUploadingChange у дропзоны. ✓ сделано (2026-09-09):
