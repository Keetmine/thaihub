# Wiki, лендинг и футер

- **`/wiki`** — публичный индекс всех опубликованных статей
  (`WikiArticle.published`), **`/wiki/[slug]`** — сама статья
  (HTML из rich-text редактора админки, `dangerouslySetInnerHTML` —
  контент только от админов). Оба пути открыты без логина (см.
  [auth.md](auth.md)); ссылки живут в футере.
- **Админка** (`/admin/wiki`) — CRUD статей с `RichTextEditor`
  (contenteditable + execCommand: заголовки, начертания, цвета,
  картинки через /api/upload), флаг «опубликовано».
- **`/about`** — лендинг по постоянному адресу: тот же `LandingPage`,
  что видят незалогиненные на `/` (для залогиненных на главной — лента
  событий, поэтому «О нас» в футере ведёт сюда). Блок примеров на
  лендинге — живые ближайшие события из афиши (3 ближайших
  occurrence, многодневные схлопнуты по eventId), не хардкод.
- **Футер** (`src/components/SiteFooter.tsx`) — колонки
  Каталог / Личное / Полезное (Помощь, Написать нам, Вики, О нас).

## Слаги и черновики

Слаг генерируется из заголовка при создании статьи и больше не
меняется: у опубликованной статьи он уже разошёлся ссылками. Если
заголовок не даёт слага (например, только на тайском), ссылка
откатывается на id.

Стартовые черновики заливает `scripts/seed-wiki-drafts.ts` — скрипт
идемпотентен (статья с тем же заголовком обновляется), уже
опубликованные статьи не трогает. Конкретика, которая устаревает,
помечена в тексте плейсхолдерами `[[…]]`.
