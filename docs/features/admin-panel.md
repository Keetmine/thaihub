# Admin panel sections

Разделы админки за пределами CRUD каталога (сайдбар, layout в
`src/app/admin/(protected)/layout.tsx`).

- **Пользователи** (`/admin/users`, `/admin/users/[id]`) — список и
  полная карточка для модерации: роль админа (`setAdminRole`, себя
  разжаловать нельзя), премиум, удаление, плитки-счётчики и весь
  контент юзера (заметки, списки, свои места, поездки, избранные
  артисты, «иду») с точечным удалением.
- **Обращения** (`/admin/feedback`) — сообщения из формы помощи
  (`FeedbackForm` на /help#feedback — страница открыта и анонимам,
  туда же ведёт CTA «напишите нам» из поиска с запросом в `context`):
  вопрос / предложение / запрос контента; статусы NEW/DONE. У формы
  есть поле почты (`Feedback.email`, анониму обязательно,
  залогиненному подставляется почта аккаунта); в админке кнопка
  «Ответить» открывает почтовый клиент (mailto с темой и цитатой).
  TODO: отправка прямо с сайта — после настройки SMTP (см. roadmap).
- **Модерация** (`/admin/moderation`) — табы с пагинацией (по 20):
  Жалобы / Отзывы / Комментарии / Заметки / Списки мест / Списки
  актёров / Свои места. У каждой карточки: автор (ссылка на
  /admin/users/[id]), «Открыть ↗» — публичная страница контента в
  новой вкладке, удаление (`adminDeleteContent`) и для текстов —
  правка на месте (`adminUpdateContentText`, details-свёртка).
- **Рассылки** (`/admin/broadcast`) — telegram-сообщение всем/премиум
  (последовательно, журнал в `Broadcast`).
- **Аналитика** (`/admin/analytics`) — регистрации по дням (30 дней,
  CSS-бары), конверсия в премиум, топ событий/артистов.
- **Финансы** (`/admin/finance`) — журнал оплат Stars (`Payment`,
  пишется вебхуком по `telegram_payment_charge_id`, upsert против
  ретраев), активные подписки, оценка MRR.
- **Импорты** (`/admin/imports`) — журнал `ImportRun` (обёртка
  `logImportRun` вокруг админских синков TMDB/GMMTV/MDL) + ссылки на
  места запуска, форма импорта агентства с tpop.fandom (см.
  [tpop-agency-import.md](tpop-agency-import.md)) и лента «последнее
  спарсенное» (`ImportedItem`) — всё, что импортёры создали/обновили
  автоматически, со ссылками на редактирование.
- **Ошибки** (`/admin/errors`) — лог серверных ошибок: хук
  `onRequestError` в instrumentation.ts пишет всё упавшее в страницах/
  экшенах/роутах в `ErrorLog` (+ `logError` для точечных catch).
- **Настройки** (`/admin/settings`) — `SiteSetting` (ключ-значение):
  цена подписки в Stars (используется инвойсом и пейволлом через
  `getPremiumPriceStars`), пустое значение = дефолт из env/кода.

На всех страницах редактирования каталога (актёр/сериал/событие/
локация/агентство) есть кнопка «Посмотреть на сайте ↗» — публичная
страница в новой вкладке; все прочие ссылки из админки на публичные
страницы (карточка юзера, модерация) тоже открываются в новой вкладке.
Аватарки-заглушки с первой буквой имени — общий компонент
`src/components/LetterAvatar.tsx` (размер/высота/скругление пропсами),
используется в списках исполнителей, юзеров, локаций, сериалов и
событий.

## Списки каталога в админке

- События: вкладки «Текущие» (есть будущие даты) / «Архив» (целиком
  прошедшие, свежепрошедшие сверху) + переключатель сортировки «по дате
  события / по дате добавления»; список без пагинации — ленивая
  подгрузка по 30 (`LazyList`).
- Сериалы: вкладки Все / В эфире / Анонсы / Вышедшие по
  `airedFrom`/`airedTo` (в эфире = начался и не закончился либо без
  даты конца).
- Пагинированные списки (`PAGE_SIZE` в `src/lib/pagination.ts`) — по 30
  на страницу; в списке актёров у имени выводится реальное имя в
  скобках (`performerOptionLabel`).
- `LazyList` (`src/components/LazyList.tsx`) — ленивое порционное
  монтирование по 30 строк через IntersectionObserver; используется и в
  публичных алфавитных списках (`AlphabetIndexList`, буквенные секции
  /artists).
