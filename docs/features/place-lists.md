# Place lists («Списки мест»)

`PlaceList` — пользовательская подборка локаций («где вкусная еда»,
«кафе из дорам») с той же моделью видимости, что у поездок
(PRIVATE/FRIENDS/PUBLIC, `src/lib/tripVisibility.ts`).

- **`/lists`** — свои списки + создание попапом; **`/lists/[id]`** —
  карта пинов + строки локаций (фото, заметка per-место, ссылка на
  страницу локации). Владелец добавляет места асинхронным поиском
  (`searchLocationOptions` — тот же паттерн, что поиск актёров),
  редактирует заметки, меняет видимость, удаляет. Чужой список
  открывается по правилам видимости (404 иначе); видимые списки друга
  показываются в его профиле (`/users/[id]`).
- **Привязка к поездкам**: вкладка «Что посетить» поездки объединяет
  три источника — локации съёмок дорам владельца (по watch-статусам),
  прикреплённые списки (`TripPlaceList`, селект «+ Прикрепить список»)
  и отдельные места (`TripPlace`, комбобокс «+ Добавить место») — все
  пины на одной карте.
- **Личное событие поездки** может ссылаться на локацию
  (`TripPersonalEvent.locationId`, `LocationPickerField` в форме) —
  карточка события показывает «📍 место» ссылкой.
- Пункт «Мои списки мест» — в выпадашке профиля.
