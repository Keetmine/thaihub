# Gamification: stats + achievements

Всё считается из уже собираемых данных (посещения, `LocationVisit`,
`DramaWatchStatus`, поездки, дружбы) — специального трекинга нет.

## Статистика (Д1)

`computeUserStats` (`src/lib/userStats.ts`) — один свод: посещённые
события (событие «посещено», когда прошла его последняя дата), уникальные
площадки, актёры вживую (+топ-5 по числу посещений), посещённые локации
(+пины для карты), досмотренные дорамы, поездки/дни в Таиланде, друзья,
разбивка по годам и булевы флаги для ачивок. Рендерится вкладкой
«Статистика» в кабинете (`account/StatsTab.tsx`): плитки, топ актёров,
CSS-бары по годам, карта посещённого (`LocationMapLoader`), сетка ачивок
с прогресс-барами.

## Ачивки (Д2)

`src/lib/achievements.ts` — 22 определения (`ACHIEVEMENTS`): счётчики
(концерты 1/5/10/25, площадки, актёры вживую, локации 5/15/30, дорамы
10/50/100, поездки) и флаги («Дубль», «Марафон» — 3 события за неделю,
«Ранняя пташка» — «иду» до старта продаж, «Неделя в Таиланде»,
«Компанией» — событие с 4+ отметившимися). Условия считаются на лету;
`syncAchievements` фиксирует новые в `UserAchievement` (момент получения)
и один раз поздравляет в Telegram. Пересчёт происходит при заходе
владельца в кабинет; публичный профиль (`/users/[id]`) показывает только
уже зафиксированные бейджи (с учётом приватности профиля).
