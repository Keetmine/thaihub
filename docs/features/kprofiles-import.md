# Разовый импорт профилей с kprofiles.com

Просьба владельца 2026-09-26: «стянем всю инфу с kprofiles, переведём и
дозаполним то, чего у нас нет; факты уникализировать и перевести, если
у нас уже есть — совместить». Не парсер по расписанию, а один проход:
список тайских актёров (`/thai-actors-actresses-list/`) и три страницы
групп (Domundi, DEXX, DMD trainee). Прошёл на проде 2026-09-26: 175
карточек обновлено, 29 заведено, 11 отложено на разбор владельцу.

## Шаги

| Шаг | Скрипт | Результат |
|---|---|---|
| 1. сбор | `scripts/kprofiles-collect.ts` | страницы в `tmp/kprofiles/html/` (кэш), профили в `raw.json` |
| 2. сопоставление | `scripts/kprofiles-match.ts` | `people.json`: у каждого `performerId` или null |
| 3. факты → пачки | `scripts/kprofiles-export-facts.ts` | `tmp/kprofiles/facts/batches/` |
| 4. пересказ и перевод | подагент по `tmp/PROMPT-facts.md` | `tmp/kprofiles/facts/out/` |
| 5. импорт | `scripts/kprofiles-import.ts [--apply]` | карточки + отчёт `tmp/kprofiles/report.md` |

Разбор страниц и сопоставление — чистые функции в `src/lib/kprofiles.ts`
(тест `tests/unit/kprofiles.test.ts`).

## Сопоставление с каталогом

`matchKpToCatalog`, признаки по убыванию надёжности: инстаграм,
настоящее имя целиком (без пробелов и дефисов), вхождение слов имени,
ник + фамилия (закрывает разную транслитерацию: «Natasitt» ↔
«Natasit»), одинокий ник — только если он у нас один. Неоднозначное не
импортируется; незнакомцам печатаются похожие по фамилии — чтобы не
заводить дубль вслепую.

## Импорт

- **Поля — только в пустое**: дата и место рождения, рост, вес, группа
  крови, MBTI, гражданство, тайское написание (в `alsoKnownAs`), фото,
  автограф (`signatureUrl`). Картинки качаются к нам.
- **Соцсети** — только недостающие платформы.
- **Факты** — пересказаны и переведены подагентом, наши слиты с новыми;
  прежние списки уходят в `TextRewrite`, `--rollback` возвращает их.
- **Новые карточки** — только без похожих в каталоге и не по обрывкам:
  профиль без полного имени, у которого нет фактов или чей ник уже есть
  в списке, — вторая страница того же человека («Peck Palitchoke»
  рядом с «Peck») или вовсе не человек.
- `kprofilesUrl` — адрес источника, только для себя, на витрине ссылки
  нет (решение владельца).

На прод конвейер гонялся на самом сервере, а не файлом: там уже были
слиты сто пар дублей, и id части артистов отличались от локальной базы.

Дальнейшие факты с внешних источников идут не так, а через очередь на
проверку — см. [facts-review.md](facts-review.md).
