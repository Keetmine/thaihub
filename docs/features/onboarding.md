# Онбординг новичка

## Что происходит после регистрации

1. `/welcome/profile` — ник (он же адрес профиля) и необязательное о
   себе.
2. `/welcome` — выбор любимых артистов, чтобы «Мои артисты», избранное и
   уведомления заработали с первого дня.
3. Тур по интерфейсу (`ProductTour`) — подсветка элемента и подсказка
   рядом, семь шагов: афиша → избранное и «иду» → актёры → места съёмок →
   поездки → уведомления → профиль.

## Как устроен тур

Своя обвязка, без библиотеки: нужен ровно этот сценарий, а внешняя
зависимость тянула бы свои стили и спорила с тёмной темой.

- Элементы помечены атрибутом `data-tour="..."`; шаг, чей элемент не
  найден на странице, **пропускается**. Вёрстка меняется, и тур не
  должен упираться в подсветку пустоты. По той же причине метка «афиша»
  стоит и на ветке с пейволлом: у новичка подписки ещё нет.
- Шаги с `href` переводят на нужную страницу клиентской навигацией.
- Автозапуск только с главной — всплывать поверх произвольной страницы,
  перехватывая клики, навязчиво.
- Факт прохождения хранится у пользователя (`User.tourCompletedAt`), а
  не в браузере: иначе тур всплывал бы на каждом новом устройстве.
- Пройти заново — кнопка в настройках профиля.

E2E-пользователи создаются с проставленным `tourCompletedAt`: иначе тур
перекрывает интерфейс и перехватывает клики в сценариях.
