# Мини-игра «Угадай сериал по постеру»

Страница `/game` (открыта гостю — есть в `PUBLIC_PATHS` прокси и в
sitemap). Ссылка на неё — в футере, колонка «Полезное». Пункт аудита
2026-09, раздел 7.

## Как играется

Показывается размытый постер случайного сериала (blur — CSS-фильтр на
клиенте, сам файл не трогается) и четыре названия: одно правильное и
три ложных. Клик — мгновенная развязка: постер расфокусируется,
правильная кнопка зеленеет, под постером — ссылка на страницу сериала.
Кнопка «Ещё» берёт следующий раунд.

Серия угадываний (стрик) и рекорд живут в `localStorage`
(`posterGame.streak` / `posterGame.best`) — базы и логина у игры нет.

## Как устроено

- `src/lib/posterGame.ts` — сборка раунда и проверка ответа;
- `src/app/(public)/game/actions.ts` — два server actions поверх lib
  (`newGameRound`, `answerGameRound`); первый раунд собирает сама
  страница, без экшена;
- `src/app/(public)/game/GameClient.tsx` — клиентская часть.

**Из чего играем** (`gamePool`, правка владельца 2026-09-10): только
**тайские сериалы последних пяти лет** и только с нашим постером
(`posterUrl` начинается с `/uploads` — внешние ссылки бывают битыми).
Каталог у нас шире, но игра — витрина сайта про лакорны, и угадывать
японский фильм 2009-го тут не про что; заодно узкий пул делает раунд
честнее — варианты похожи, и правильный не выдаёт себя одной строкой.
Год считается при каждом раунде, а не при старте процесса: сервер живёт
месяцами, и «последние пять лет» не должны застыть.

Ложные варианты берутся из ТОГО ЖЕ пула, ярусами: сначала тот же тип
(сериал к сериалу, фильм к фильму), потом весь пул. Постер им не нужен,
названия сравниваются на языке зрителя, чтобы не попалось два
одинаковых.

Правильный ответ на клиент заранее не уезжает: раунд несёт четыре
непомеченных варианта и токен — id правильного сериала, зашифрованный
AES-GCM ключом процесса. Проверка — второй вызов экшена. Ключ живёт до
рестарта сервера: протухший токен отдаёт `status: "expired"`, клиент
объясняется и берёт новый раунд.

Словари — раздел `game` (`src/lib/i18n/{en,ru}/game.ts`), подпись
ссылки в футере — `nav.game`.
