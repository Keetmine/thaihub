# MyDramaList import

Точечный импорт данных сериала со страницы mydramalist.com — кнопка
«Подтянуть с MyDramaList» на `/admin/dramas/[id]/edit`.

## Как это работает

Официального публичного API у MDL нет (ключи выдают только «партнёрам»
по заявке), но страницы отдаются обычным GET'ом с браузерным
User-Agent — Cloudflare-челленджа нет. `src/lib/mydramalist.ts`
(`fetchMdlDrama(url)`) парсит две вещи:

- **schema.org JSON-LD** (`TVSeries`/`Movie`) — название, постер,
  описание, жанры, рейтинг, каст (каст пока не используется);
- **блок Details в HTML** (тэги срезаются, текст матчится по меткам) —
  родное название, `Aired: <from> - <to>`, Original Network, Episodes.

Статус (`DramaStatus`) на странице отдельным полем не существует — он
выводится из дат эфира: старт в будущем → `PLANNED`, финал в прошлом →
`ENDED`, иначе `RETURNING_SERIES`.

## Что пишется в базу

Серверный экшен `importFromMydramalist` (admin/dramas/actions.ts) берёт
ссылку из поля `mydramalistUrl` формы, **заполняет только пустые
поля** — описание, год, канал, постер (скачивается локально в WebP
через `downloadRemoteImage`, папка `uploads/mdl`) — и всегда освежает
статус. Занятые поля не перезаписываются; кнопка показывает, что
заполнено, а что уже было.

Поиск (`https://mydramalist.com/search?q=...`) тоже парсится обычным
GET'ом — задел на автоматический матчинг по названию, пока не
используется.
