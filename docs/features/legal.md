# Юридические страницы и согласия

Владелец — самозанятая в Республике Беларусь; базовый закон — РБ № 99-З
«О защите персональных данных», аудитория в основном в РФ (оглядка на
152-ФЗ). Всё сделано своими силами, без юристов.

## Документы

- `/terms` (`src/app/(public)/terms/page.tsx`) — условия: подписка
  (промокод/по договорённости, Stars — когда включена настройка
  `payment_mode`), возврат, правила, контент из открытых источников
  (правообладателям — ответ в течение 7 дней), ссылка на политику.
- `/privacy` (`src/app/(public)/privacy/page.tsx`) — политика
  конфиденциальности: что собираем, зачем, куки, третьи сервисы
  (Метрика, Sentry, Telegram, Google), трансграничная передача, как
  удалить аккаунт. **Блок «Оператор» пока без реквизитов — ждёт ФИО от
  владельца.**
- Ссылки на оба — в футере (`SiteFooter`).

## Согласие на куки

`src/components/CookieConsent.tsx` (рендерится из корневого layout):
плашка в нижнем углу с «Принять все» / «Только необходимые», выбор — в
куке `cookie_consent` (all|necessary, год). Яндекс.Метрика
(`src/components/Analytics.tsx`, счётчик из `YANDEX_METRIKA_ID`) и
**Google Tag Manager** (`src/components/GoogleTagManager.tsx`,
контейнер из `GTM_ID`) подключаются ТОЛЬКО при `all` — вебвизор пишет
действия пользователя, а через GTM приходит гугловая аналитика со
своими куками; без согласия такое включать нельзя.

У GTM намеренно НЕ подключена noscript-версия (iframe сразу после
`<body>`, как в инструкции Google): она грузит тот же контейнер в
обход согласия, а без JS согласие всё равно не получить. По той же
причине сам фрагмент стоит не «как можно ближе к началу `<head>`»,
как просит Google, а после ответа на баннер — иначе гейт не имел бы
смысла. Плата за это: первый заход до ответа на баннер в аналитику не
попадает. Sentry Session Replay при ошибках
(`src/instrumentation-client.ts`) тоже гейтится этим согласием; сами
отчёты об ошибках без записи сессии шлются всегда (диагностика
работоспособности). До выбора аналитика не грузится вовсе.

## Согласие при регистрации

Форма `/signup`: обязательный чекбокс `acceptTerms` (проверяется и в
server action) + текст под кнопками Google/Telegram «Входя через …, вы
соглашаетесь…».
